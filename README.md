# Cover-Letter Creator

A Python-based application designed to streamline job applications by extracting information from job postings and organizing it for tailored cover-letter creation.

This project is actively under development, with ongoing improvements and regular commits to GitHub.

## Overview

The Cover-Letter Creator combines a Python backend with a Chrome extension to simplify the process of gathering job-posting information and preparing tailored application materials. The project focuses on application development, browser integration, API communication, and workflow automation.

## Technologies

- **Python** - Application logic and backend development
- **FastAPI** - Backend API framework
- **JavaScript** - Chrome extension functionality
- **Chrome Extensions API** - Interaction with job-posting webpages
- **Git and GitHub** - Version control and ongoing development
- **Google Docs API** - Document integration
- **Google Sheets API** - Spreadsheet integration
- **Ollama** - Local language model integration

## Key Components

- **Job Posting Extraction:** Chrome extension designed to retrieve relevant information from job postings.
- **Backend Application:** FastAPI backend for processing information and coordinating application functionality.
- **Document Integration:** Google Docs API integration for working with cover-letter documents.
- **Spreadsheet Integration:** Google Sheets API integration for organizing job application information.
- **Local AI Integration:** Ollama integration for generating tailored text using a locally running language model.
